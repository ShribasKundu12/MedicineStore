# 💊 Medicine Store Website

A web application created by advance java concepts, that simulates an online medical store. Users can browse, search, and purchase medicines while the admin can manage inventory and orders.

---

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- AJAX

### Backend
- Java (JSP & Servlets)
- JDBC
- MySQL

### Server
- Apache Tomcat

---

## 🔐 Features

- User registration and login
- Admin dashboard for inventory management
- Search medicines with AJAX autocomplete
- Add to cart and place orders
- Session-based user authentication
- Secure database operations with JDBC
